# Дневник питания
Этот проект предназначен для упрощения выбора питания и слежения за ним. Он помогает составить план и меню.
## Функции
1. Рассчёт каллорий
2. Составление меню
## Для чего это надо
- Помогает поддерживать правильное питание
- Помогает достигать целей и вырабатывать полезные привычки

## Пример дневного меню
```python
Завтрак: овсяная каша, вареное яйцо или омлет, чай или кофе без сахара.
Обед: суп, гарнир(гречка, рис), белковое блюдо(запечена куриная грудка или рыба), салат из свежих овощей.
Перекус: творог или греческий йогурт, фрукты.
Ужин: легкое белковое блюдо(рыба, филе индейки), порция тушеных овощей, кефир или зеленый чай.

```
